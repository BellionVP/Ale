# Un jardín para dos

Carta interactiva hecha con React, TypeScript y Vite. Las fotografías se sirven desde `public/fotos`.

## Desarrollo

```sh
npm install
npm run dev
```

## Producción

```sh
npm run build
npm run preview
```

Para publicarla en Vercel, importa este directorio como proyecto. Vercel detecta Vite automáticamente; el comando de compilación es `npm run build` y la carpeta de salida es `dist`.

El texto de la carta y las secciones se pueden personalizar en `src/App.tsx`.
